# 🍰 Sistema de Gestión Pastelería Soto (Backend/ERP)

![Status](https://img.shields.io/badge/Status-En%20Desarrollo-green)
![Tech](https://img.shields.io/badge/Stack-ASP.NET%20Core%20%7C%20Vanilla%20JS-blue)

Este es un sistema integral de **Control de Inventario y Gestión de Pedidos** diseñado específicamente para la administración interna de la **Pastelería Soto**. A diferencia de una tienda convencional, esta plataforma está optimizada para la operación del negocio, facilitando la toma de decisiones y el flujo de trabajo operativo.

---

## 🚀 Características Principales

El sistema se divide en módulos críticos para el funcionamiento de la empresa:

* **Dashboard Administrativo:** Visualización en tiempo real de métricas clave del negocio.
* **Gestión de Ventas y Pedidos:** Control total sobre las transacciones y el seguimiento de pedidos personalizados.
* **Inventario y Compras:** Registro detallado de insumos y productos terminados.
* **Control de Usuarios & Auth:** Sistema de autenticación seguro para diferentes roles administrativos.
* **Registros:** Historial completo de movimientos para auditoría interna.

---

## 🛠️ Stack Tecnológico

### **Backend**
* **Lenguaje/Framework:** .NET 8 / C#
* **Arquitectura:** Clean Architecture (N-Layer)
* **Base de Datos:** SQL Server (Entity Framework Core)
* **Seguridad:** Autenticación JWT / Identity

### **Frontend**
* **Tecnologías:** HTML5, CSS3 (Custom Properties), JavaScript Vanilla.
* **Diseño:** UI Minimalista enfocada en la eficiencia del operador.
* **Componentes:** Tablas dinámicas con paginación, filtros de búsqueda avanzada y modales interactivos.

## 📂 Estructura del Proyecto

```bash
├── Backend/              # Solución de .NET (API, Domain, Infrastructure)
├── Frontend/             # Interfaz de usuario (Vanilla JS)

│   ├── css/              # Estilos modulares (estilos.css)

```
